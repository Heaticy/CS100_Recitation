# R5口播教学视频工程

使用用户提供的逐页稿，通过火山引擎豆包语音合成生成旁白，并在原课件上叠加代码行高亮、区域框选与指示箭头。视频包括课堂内容和练习解析，目标约45分钟。

## 输入与叙述安排

- `source.txt`保存用户逐页稿，原有时间为估计值。
- `production-note.txt`保存不参与朗读的制作说明、页码规则和本轮要求。
- `prepare.py`按当前PDF准备56个画面、逐段旁白与动画位置，固定课件快照和SHA-256。
- 视频顺序为PDF的P1—P40、P42—P56、P41，练习解析之后再致谢；原PDF顺序不变。
- 加入简短的引导讲解，让视线跟随代码和图示；对原稿的代码不一致之处做小幅校正，记录在生成的`corrections.json`。

生成音色为豆包的普通话自然女声`zh_female_vv_uranus_bigtts`，资源为`seed-tts-2.0`。首次生成以`-15`语速请求，再根据实际音频测量做小幅节奏调整。

## 运行

需要Python3、requests、PyMuPDF、Pillow，以及支持libx264和libass的FFmpeg。

从课件仓库根目录执行：

```bash
python3 r5/narration/prepare.py
python3 r5/narration/synthesize.py --workers 2
python3 r5/narration/render.py --workers 3 --target-minutes 45
```

合成脚本从环境变量`VOLC_TTS_API_KEY`读取凭据，也可用`--key-file`指定本机私密文件。不要将凭据写进代码、命令行参数值或提交。默认输出目录为被Git忽略的`r5/build/narration/`，临时凭据应在制作结束后清理。

音频按文本、音色和语速缓存。重试复用已经完成的段落；视频按画面、音频和高亮内容校验缓存。`--pages 5`可渲染某一页作为样片；`--tempo`可在局部修订时沿用已验证的节奏。

## 交付文件

全部位于`r5/build/narration/`：

| 文件 | 用途 |
|---|---|
| `CS100_Recitation5_口播教学.mp4` | 1080p、10fps、H.264／AAC，带章节及可切换中文字幕 |
| `CS100_Recitation5_口播音频.m4a` | 独立旁白音轨，包含教学停顿 |
| `CS100_Recitation5_口播字幕.srt` | 中文字幕，段落使用实际音频边界，段内短句按长度分配时间 |
| `CS100_Recitation5_口播稿.txt` | 最终稿，标明视频时间、PDF物理页和底部页脚编号 |
| `chapters.txt` | 章节入口时间 |
| `delivery.json` | 成片时长、大小、画面参数与SHA-256 |
| `timeline.json` | 各页和各旁白段落的时间映射 |
| `pacing.json` | 实测语音时长、停顿及节奏参数 |
| `corrections.json` | 原稿与代码不一致之处的修订记录 |
| `slides.pdf` | 本次制作使用的课件快照 |

字幕未烧入画面，播放时可按需开启，以保证代码和底部内容完整可读。字幕段内时间不是逐字强制对齐；页切换及旁白段落边界以真实音频为准。

## 节奏与动画

提问后留思考时间，长代码、内存布局与关键流程讲完后留阅读时间，章节和翻页留短缓冲。停顿不是用长时间静帧凑时长。框选与箭头渐入渐出，复杂段落按实际音频长度依次指向多个位置。

练习先展示题目并留思考停顿，再切到答案页。复用课件里的原图与源码位置，不修改教学源码，也不把练习提前显示答案。

## 验证

制作后应检查：全部音频完整返回、音画总时长、56页顺序、章节与字幕范围、开头／中间／结尾及练习转场、高亮不挡字、最终文件完整解码、音频响度与SHA-256。口播为合成语音，术语发音应结合样片复核。
