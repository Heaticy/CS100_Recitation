原TODO模板保留在工作区`homework/`，本课件目录不再重复存放。原文件未包含完整解答、HW1 P2的BinB原始错误程序、HW1／HW2完整题面及全部输入范围。

除HW0题面片段外，示例均为依据已知题意编写的课堂调试变体。多项式固定为P(x)=1+2x+3x²，不推测正式作业的输入协议。求和溢出演示的INT_MAX边界用于观察UBSan，不宣称其属于正式输入范围。全部当前案例均使用C17；释放后使用是独立的C内存管理示例，不作为禁止动态内存的作业实现。

这些示例用于定位错误、解释规则和验证修复，不作为完整作业标准答案。
