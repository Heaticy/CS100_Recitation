# CS100 Recitation 7：C++Class基础

本讲面向需要复习C++类基础的学生，以Lecture14中的`Student`为贯穿案例，用姓名、学号和入学年份说明对象如何保存信息、通过接口维护数据约束，以及如何开始和结束生命周期。重点是封装、接口设计与`const`成员函数，代码使用C++17。

## 内容结构

- **对象与接口**：Class与Object、成员变量与成员函数、`m_`命名、三种访问权限、`struct`与`class`的默认权限，以及隐藏数据和检查输入的意义。通过单片机开发板与笔记本的使用方式类比接口边界。
- **查看与const**：`this`如何指向当前对象、查看函数末尾的`const`承诺，以及`const`对象调用非`const`成员函数的编译错误。
- **初始化与生命周期**：构造函数、成员初始化列表与声明顺序、默认构造、析构，以及`malloc/free`、`new/delete`和`new[]/delete[]`的区别与配对。

## 构建与代码检查

课件依赖与仓库根README一致，需要Linux或WSL、make、XeLaTeX、latexmk、TeXLive及NotoCJK字体。代码检查需要Python3和支持C++17的编译器，默认使用`c++`，可用`CXX=g++`指定。

从仓库根目录执行：

```bash
make -j -C r7
make -C r7 check-demos
```

PDF输出为`r7/build/CS100_Recitation7.pdf`。也可进入`r7/`运行`make -j`和`make check-demos`。`build/`保存编译与检查产物。

`check-demos`为课堂片段补齐所需上下文，按C++17编译，检查接口输入、对象状态、访问权限、`const`与生命周期。正常片段检查运行结果；故意展示错误的片段检查编译器是否拒绝，避免将错误代码作为可运行程序。

## 代码片段的阅读方式

`.inc`是教学片段，可能省略头文件、外围类或`main`，不应单独编译。每页会说明代码所在位置；带有`Error`或`compile error`注释的行用于分析编译错误。不同页面逐步补充或替换`Student`的相关部分，不能把所有片段直接拼成一个类。

成员变量统一使用`m_`前缀，例如`m_name`、`m_id`和`m_entranceYear`；参数和局部变量使用`name`、`year`、`years`等名字。成员函数采用小驼峰命名，例如`setName`和`getName`。`Student`要求姓名和学号非空、入学年份在1900至2100之间；构造函数建立有效初始状态，修改接口继续维护约束。创建时必须提供这三项信息，本课`Student`不提供默认构造函数。

## 页面安排与建议进度

PDF共25个物理页，其中20个为编号正文帧；另含封面、3个章节页和结束页。下表使用PDF物理页，提问与讨论时间计入约60分钟课堂。

| PDF物理页 | 内容 | 建议进度 |
|---|---|---|
| 1–3 | 封面、课程目标与第一章导入 | 0–3分钟 |
| 4–11 | 对象、命名、访问权限、封装与接口 | 3–25分钟 |
| 12–16 | `this`、`const`查看函数与编译错误 | 25–40分钟 |
| 17–24 | 构造、初始化、析构与动态对象 | 40–59分钟 |
| 25 | 结束与答疑 | 59–60分钟 |

课堂重点让学生说明三件事：无效输入为什么不能改变原状态，查看函数为什么要声明为`const`，动态创建对象后为什么需要匹配的释放操作。
