\section{编译器的安装}

\begin{frame}{编译器的安装}
    安装方式按平台分三类：
    \begin{itemize}
        \item \textbf{Linux}：\code{gcc}/\code{g++}
        \item \textbf{Windows}：通过WSL使用\code{gcc}/\code{g++}
        \item \textbf{Mac}：自带\code{clang}/\code{clang++}
    \end{itemize}
\end{frame}

\begin{frame}[fragile]{Linux（以Ubuntu为例）}
    一行命令即可安装默认版本的\code{gcc}和\code{g++}：
    \begin{Code}*
        \lstinputlisting{code/setup/install-gcc.sh}
    \end{Code}
    或者安装\code{build-essential}（含make等常用工具）。

    在Ubuntu24.04默认安装的是gcc-13，26.04默认安装的是gcc-15。

    每个新版本的GCC都会增加对更新标准的支持：
    \begin{itemize}
        \item gcc-9：对C++17支持比较完善；
        \item gcc-11：改进了C++20的支持；
        \item gcc-13/14：开始逐步实现C++23的特性。
    \end{itemize}
    同时编译器优化更强，错误检查与诊断也更好。
\end{frame}

\begin{frame}[fragile]{Windows（WSL）}
    WSL（Windows Subsystem for Linux，Windows的Linux子系统）是微软推出的一项功能，它允许在Windows上原生运行Linux环境，无需虚拟机或双系统。

    换句话说：在Windows里，你可以直接打开一个Linux终端，运行\code{apt}、\code{bash}、\code{gcc}、\code{python}等工具，就像真的在Linux下一样。

    \textbf{从这学期开始，课程演示全部在Linux环境下进行}：Windows用户请全程使用WSL，Mac用户直接使用自带终端。
\end{frame}

    Windows自带WSL一键安装命令，\textbf{在管理员权限的PowerShell}中执行：
    \begin{Code}*
        \lstinputlisting{code/setup/wsl-install.sh}
    \end{Code}
    会自动安装WSL和默认的Ubuntu，装完\textbf{重启电脑}生效。

    \begin{itemize}
        \item \textbf{首选}：网络正常（有梯子）直接执行即可。
        \item \textbf{次选（无梯子）}：先去GitHub的\code{microsoft/WSL} releases下载最新\code{.msi}手动装上WSL本体，再执行\code{wsl --install}安装Ubuntu；若安装卡在0\%，可加参数\code{--web-download}。
    \end{itemize}

    装完Ubuntu后首次打开，会让你创建一个用户名和密码（注意密码输入时屏幕不显示字符，是正常的）。
\end{frame}

\begin{frame}[fragile]{WSL安装的版本选择}
    \code{wsl --install}默认安装\textbf{最新LTS}（当前是Ubuntu26.04）。两种版本本课程都支持：
    \begin{itemize}
        \item \code{wsl --install}：Ubuntu26.04（默认gcc-15）；
        \item \code{wsl --install Ubuntu-24.04}：Ubuntu24.04（默认gcc-13）。
    \end{itemize}

    装好后用\code{cat /etc/os-release}确认版本，后面换源时选择对应的脚本。
\end{frame}

\begin{frame}[fragile]{WSL环境配置：换源}
    首次进入WSL后，先把软件源换到国内镜像，否则\code{apt}下载很慢。

    先执行\code{cat /etc/os-release}确认Ubuntu版本（看\code{VERSION\_CODENAME}），然后按版本选择换源脚本：
    \begin{itemize}
        \item Ubuntu24.04（noble）：\code{magic\_code\_2404.md}
        \item Ubuntu26.04（resolute）：\code{magic\_code\_2604.md}
    \end{itemize}

    \begin{vspquotered}{版本必须匹配}
        24.04的机器用26.04的源（或反过来）会导致仓库里所有包都比系统旧，\code{apt install}会报依赖错误。
    \end{vspquotered}
\end{frame}
